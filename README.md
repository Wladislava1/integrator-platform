# Integrator Platform — Связь ID

Платформа единого входа **Связь ID** для физического лица и каталог продуктов.  
Продукт не заводит свой пароль: он спрашивает платформу, кто вошёл, и получает имя и почту. Проверка пойдёт на отдельном тестовом продукте: он показывает имя и почту вошедшего. Этот запрос и тестовый продукт обязательны в семестре и ещё не реализованы. Сейчас работают регистрация, вход, профиль и тема. Каталог пока из пустых слотов.

Спецификация версии 1.1: [docs/01-requirements.md](docs/01-requirements.md).

## Запуск

```bash
git clone https://github.com/Wladislava1/integrator-platform.git
cd integrator-platform
cp .env.example .env
npm ci
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

### Проверка работоспособности

1. Откройте `/register`, создайте пользователя.
2. После регистрации откроется каталог со слотами продуктов.
3. Зайдите в «Профиль»: личные данные и смена пароля; тема — в шапке.

Автоматический smoke (сервер должен быть запущен):

```bash
npm run smoke
```

Swagger UI: [http://localhost:3000/api-docs](http://localhost:3000/api-docs) (спека `public/openapi.json`).

План рассказа преподу: [docs/demo-plan.md](docs/demo-plan.md).
