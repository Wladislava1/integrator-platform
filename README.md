# Integrator Platform — СвязID

Платформа единого входа **СвязID** для физического лица и каталог продуктов-заглушек.  
Другие продукты будут подключаться позже через API; в Lab 1 — каркас, регистрация, вход, профиль и тема.

## Стек и версии инструментов

| Инструмент | Версия |
|------------|--------|
| Node.js | ≥ 20 (проверено на 22.17.0) |
| npm | ≥ 10 |
| Next.js | 15.1.0 |
| React | 19 |
| TypeScript | 5 |
| Tailwind CSS | 3.4 |

Зависимости зафиксированы в `package-lock.json`.

## Запуск

Предварительные требования: установленные Node.js 20+ и npm.

```bash
git clone <URL-репозитория> integrator-platform
cd integrator-platform
cp .env.example .env
npm ci
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

### Проверка работоспособности

1. Откройте `/register`, создайте пользователя (ФИО, email, пароль дважды).
2. После регистрации откроется каталог с пунктирными слотами продуктов.
3. Зайдите в «Профиль» и «Настройки» (светлая/тёмная тема).

Автоматический smoke (сервер должен быть запущен):

```bash
npm run smoke
```
